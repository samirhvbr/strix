The wider MCP suite hit a timing assertion also reproduced on unchanged main. Ruff, Bandit and Mypy across 137 source files passed. Pyright retains the same 945 diagnostics. - [Issue #1736](https://github.com/usestrix/strix/issues/1736) reproduces `write_stdin` corrupting an escaped backslash sequence inside a valid Python REPL command. The control used the same SDK and real PTY without the wrapper. The decoding pass also supports escaped Ctrl-C intentionally, so the issue asks maintainers to define the literal and control-key input contract. [Compatibility change #499](https://github.com/usestrix/strix/pull/499) · [Argument-shape change #957](https://github.com/usestrix/strix/pull/957)

The issue asks maintainers to define canonical source identity, including legacy reports and repeated checkouts. [Manifest scope #982](https://github.com/usestrix/strix/pull/982) · [Path normalization #1678](https://github.com/usestrix/strix/pull/1678)
